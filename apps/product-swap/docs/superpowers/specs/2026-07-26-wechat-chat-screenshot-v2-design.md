# 微信聊天截图模板 V2 设计

## 目标

在现有微信聊天截图模板上完成四项改进：

1. 长对话自动拆成多张 1080×1920 PNG，不再因超出画布而报错。
2. AI 对话更丰富、更有安利感和夸张情绪，同时不编造价格、优惠、销量、地址或联系方式。
3. 使用站内搜索替换失效的腾讯旧选点 iframe，稳定搜索并选择真实 POI。
4. 内置一组本地 SVG 头像，左右双方可独立选择。

## 已确认的地图根因

线上复现显示，旧选点组件会重定向到 `mapapi.qq.com`，再从该域名请求腾讯地点搜索。当前 Key 的域名白名单拒绝该来源，腾讯返回 `status=110`，组件因此固定显示“获取消息列表失败”。

本次不继续依赖旧 iframe，也不要求用户额外修改腾讯控制台。站内地图搜索通过 Cloudflare Worker 调用腾讯 WebService 地点搜索，Worker 使用已验证可用的正式站点 Referer；浏览器只接收经过裁剪的地点结果。

## 方案选择

### 采用：站内搜索、多页 Canvas、内置 SVG 头像

- 地图搜索体验、错误提示和结果样式由本站控制。
- 每条消息保持完整，不会被截断到两张图中。
- 头像不依赖外部图片服务，导出不会污染 Canvas。
- 继续复用现有聊天编辑器、静态地图代理和 Cloudflare Secret。

### 不采用：继续使用腾讯旧选点组件

需要在腾讯控制台额外放行组件运行域名，且组件自身仍可能变更或重定向，问题难以由本站控制。

### 不采用：生成一张无限长图

超长图片不符合常见手机聊天截图比例，也不便于发布到短视频或图文平台。

## 多页布局与导出

渲染器新增分页布局：

- 每页固定 1080×1920。
- 每页重复状态栏、联系人标题和背景。
- 消息按顺序填入页面；若下一条消息超过安全底边，则整条移到下一页。
- 不拆分文字气泡、图片或地点卡片。
- 单条消息的现有最大尺寸小于单页内容区，因此不存在单条消息无法容纳的问题。
- 页面数量由内容自然决定，不设置人为的一页消息数。

编辑器将单个 Canvas 预览替换为多页预览列表。每页带“下载第 N 张”按钮；“下载全部”按页触发 PNG 下载，文件名为 `微信聊天截图-01.png`、`微信聊天截图-02.png`。若浏览器限制自动多文件下载，用户仍可使用每页按钮。

## AI 对话风格

后端草稿合同调整为：

- 10–16 条消息。
- 单条文字最多 120 字，总文字最多 1000 字。
- 必须包含左右双方，且所有图片、地点引用各出现一次。
- 语气允许明显兴奋、连续追问、感叹、口语化停顿和少量表情符号。
- 鼓励从味道、氛围、出片感、服务感受等主观角度展开。
- 禁止编造可核验事实，包括价格、优惠、销量、排队时长、具体菜品、地址和联系方式。

前端继续严格验证 AI 返回结构。若 AI 首次返回无效结构，保留现有一次带上下文修复流程。

## 腾讯地点搜索

### 前端

地图弹窗包含：

- 城市或区域输入框，例如“北京”。
- 店铺或地点关键词输入框，例如“颐和园”。
- 搜索按钮、加载状态、空结果和错误提示。
- 最多 12 条结果，每条展示名称、地址和城市。

用户选择结果后，编辑器保存：

```json
{
  "id": "store-location",
  "name": "颐和园",
  "address": "北京市海淀区新建宫门路19号",
  "city": "北京市",
  "lat": 39.999,
  "lng": 116.275
}
```

地点卡片继续通过现有 `/map-preview` 代理加载腾讯静态地图。

### 后端

新增：

```text
GET /api/product-swap/location-search?region=北京&keyword=颐和园
```

Worker 固定请求腾讯官方 `/ws/place/v1/search`，使用：

- `boundary=region(<region>,1)`
- `page_size=12`
- Cloudflare Secret 中的 `TENCENT_MAP_KEY`
- 固定正式站点 Referer

输入限制为区域 40 字、关键词 40 字；响应只保留地点 ID、名称、地址、城市和中国境内有效经纬度。上游超时、非 JSON、非零状态或超限响应统一映射为稳定错误，不向浏览器泄露 Key 或腾讯原始响应。

## 头像

新增 8 个本地 SVG 头像，风格为简洁、明亮、偏社交应用插画。编辑器为左侧好友和右侧本人分别提供头像选择器：

- 默认选择不同头像。
- 选择后立即刷新所有分页预览。
- 导出时使用所选头像。
- 头像仅属于本地展示设置，不发送给 AI。

若头像加载失败，渲染器回退到当前字母/颜色头像，导出仍可完成。

## 错误处理

- 长对话：自动分页，不显示“聊天内容超出画布”。
- 地图搜索缺少区域或关键词：在弹窗内提示，不发请求。
- 地图搜索无结果：显示“没有找到地点，请尝试更具体的名称”。
- 地图上游失败：保留用户已填写的名称、图片和 AI 草稿，可重试搜索。
- 多页中任一页渲染失败：保留上一版成功预览，不替换为半成品。
- 头像失败：使用渲染器内置回退头像。

## 测试

- 分页单元测试：短对话 1 页、长对话多页、消息不拆分、顺序不变。
- PNG 渲染测试：每页尺寸和文件名正确。
- AI 合同测试：10–16 条、120/1000 字限制、丰富风格提示存在。
- 地图路由测试：参数编码、固定腾讯域名、Referer、响应裁剪及错误映射。
- 地图前端测试：搜索请求、结果规范化、选择地点。
- 头像测试：目录清单、左右选择、加载失败回退。
- 浏览器测试：真实编辑流程生成多页、切换头像、选择地图结果、逐页导出。
- 部署后线上测试：腾讯真实 POI 搜索、静态地图 PNG、AI 多消息草稿和模板页面。
